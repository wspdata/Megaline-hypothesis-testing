# Megaline-hypothesis-testing
Projeto de análise de dados aplicado à empresa Megaline. A empresa oferece dois planos pré-pagos — Surf e Ultimate — e o objetivo foi determinar qual plano gera mais receita para orientar o orçamento de publicidade. A análise foi realizada com base em dados de 500 clientes ao longo de 2018, cobrindo chamadas, mensagens e consumo de internet.
